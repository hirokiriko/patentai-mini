# Patent Prior-Art Check PoC

個人利用向けの PoC です。目的は、**ユーザーがアップロードした自分の特許案**を起点に、J-PlatPat 用の検索式生成、検索結果の再アップロード、既存特許との**請求項・構成要素レベルの重なり検出**、および**拒絶リスクの早期把握**までを一連で扱うことです。

## 目標
- 特許案から検索語・同義語・観点語を抽出する
- J-PlatPat で使う検索式案を生成する
- ユーザーが J-PlatPat で検索し、結果を CSV 等で持ち帰る
- 持ち帰った既存特許群を解析し、自身の請求項との重複要素を可視化する
- 「どの要素が危ないのか」「何が差分候補か」を報告する

## 非目標
- 弁理士・弁護士レベルの法的判断の代替
- 本番レベルの堅牢性、強固な認証認可、高度な監査ログ
- J-PlatPat の自動操作

## PoC の基本方針
- まずは**人間が J-PlatPat を操作する前提**で組む
- AI は検索式生成と比較分析に集中する
- DB は最小構成でよい。初期は SQLite + ファイル保存で足りる
- ベクトル検索は後付け可能な形にする

## 主要フロー
1. ユーザーが自分の特許案をアップロード
2. AI が請求項・課題・作用効果・構成要素を抽出
3. AI が J-PlatPat 用検索式を複数案生成
4. ユーザーが J-PlatPat で検索し、検索結果をダウンロード
5. ユーザーが結果ファイルを再アップロード
6. システムが既存特許を解析し、重複候補・差分候補を算出
7. レポートを返す
