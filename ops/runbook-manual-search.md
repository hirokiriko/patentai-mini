# Runbook: Manual Search with J-PlatPat

## この Runbook の役割
J-PlatPat は無料で提供される特許情報検索サービスです。citeturn0search1turn2search11
本 PoC ではここを**人間が操作する外部工程**として扱います。

## Issue #86の今回限定検証

`LOCAL_AUTONOMOUS_EXECUTION_V2`では、公開・架空TXTから作る新規案件で
本サービスの実DB・実AI・実画面をLocal Codexが検証する。J-PlatPat検索の
自動操作、顧客・実案件dataの受入れ、公報投入は対象外とする。この外部検索
工程のユーザー操作を今回の完了条件に追加せず、本サービス内の検証成功を
J-PlatPat調査完了と扱わない。秘密境界、回数・費用上限、対象限定cleanupと
実測による完了判定は、`AGENTS.md`の今回限定規則とIssue #86本文に従う。

## 手順
1. システムで生成された `broad / balanced / narrow` の検索式を確認する
2. J-PlatPat の「特許・実用新案検索」で検索する
3. 必要に応じて検索条件を微修正する
4. 検索結果を CSV 出力する
5. CSV を本サービスへ再アップロードする

## 運用上の注意
- CSV 出力の利用には申請・ログインが必要な手順がある。ログイン後、画面右下に CSV ダウンロードボタンが表示される。citeturn2search0
- 特許・実用新案検索では、検索結果の CSV 出力件数上限が 500 件から 3,000 件に拡張された案内がある。citeturn2search4
- 検索結果が 500 件以下の場合、要約を含めた CSV 出力が可能と操作マニュアルに記載がある。citeturn2search0

## PoC で最低限欲しい持ち帰り物
- 検索結果 CSV
- 使った検索式
- 必要なら重要文献の PDF

## この工程で記録しておくべきこと
- どの検索式を使ったか
- 何件ヒットしたか
- 除外語や追加語を何に変えたか
- CSV が何件取れたか

## なぜ記録が必要か
複数セッション開発では、検索過程を残さないと「なぜこの文献が候補に入ったのか」が再現不能になります。これは取りこぼしの温床です。
