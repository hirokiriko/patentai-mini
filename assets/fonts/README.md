# Period PDF font

Noto Sans JP Regular, unmodified static OpenType Japanese subset, version 2.004.

- Official source: https://github.com/notofonts/noto-cjk/tree/Sans2.004/Sans/SubsetOTF/JP
- Font: https://raw.githubusercontent.com/notofonts/noto-cjk/Sans2.004/Sans/SubsetOTF/JP/NotoSansJP-Regular.otf
- License: SIL Open Font License 1.1; see `OFL.txt` for copyright and conditions.
- SHA-256: `dff723ba59d57d136764a04b9b2d03205544f7cd785a711442d6d2d085ac5073`

The OFL permits embedding and redistribution with the software, including commercial use,
provided the copyright/license is retained. The font is not sold separately or modified.
Generated documents are not required to use the OFL. No operating-system or private font is used.

The normal Docker copy includes this directory; Next file tracing includes it for API routes.
Generation checks each code point against this font and fails closed for missing glyphs.
There is no request-time font download.
