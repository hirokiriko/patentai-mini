## 操作と比較範囲

案件の「文献・請求項を選んで根拠付き比較」から、基準請求項と2〜3件の文献、各文献の請求項、文献名・版を指定する。保存原文を表示し、原本の番号・全文末尾・従属参照・画像や数式の欠落がないことを実行者が照合する。対応形式は、行頭の `【請求項1】` を連番で持つ日本語のnative text。請求項内の画像・数式マーカー、欠番、重複、不明な参照・循環、省略、欠損文字は要確認として停止する。PDF/OCRから消失した情報はテキストだけでは検出不能であり、原本照合の申告を機械的な完全性証明と呼ばない。

`draft_patents.parsed_text` と `prior_art_documents.claims_text` を直接採用する。旧 `extractedClaimsJson` の15,000文字入力上限・1,200文字fallbackや2,000文字先行文献入力は新しい比較の正本にしない。番号のないCSV/corpusテキスト等は推測して番号を付けず、原本に対応する資料の再取込みを案内する。全文とは指定請求項と必要な従属参照の全文であり、非選択請求項・明細書全頁・図面・検索網羅性を保証しない。

## 有限な計画と検証

既存managedの参照閉包、比較計画、全組合せ検査、引用一意性・原文一致・UTF-16位置の検証をadapterから再利用する。明示した文献をAI screeningで落とさない。比較専用の同期API metadataは240秒、原文読取・比較生成・保存前査読は単一の全体230秒、個別最大210秒とする。後続呼出しも全体期限の残時間に制限され、各回210秒を保証するものではない。最大3回、retry 0。生成は8,192 tokens、既知Azure GPT-5.4の原文読取は16,384 tokens、査読は22,528 tokensとする。他providerの上限は8,192 tokensを維持する。新規生成は最大4組を1回へ束ね、受信した全組合せの欠落・二重・追加を検査して元の最大2組chunkへ分配し、既存decoderを維持する。原文だけの読取1回→生成1回→査読1回の順序を固定し、全文・最大索引・最大草稿・schema・framing込み90,000 bytesを送信前に検査する。旧2生成batchが必要な範囲は4回目を追加せず、全体を送信前停止する。このため旧版で受理できた入力がplan_limitになる場合がある。2文献×2組、3＋1組、3文献各1組は単一batchに収まるときに対応する。旧6組の保存結果は引き続き読める。

時間枠は共有budget内の閉じた比較専用capabilityで適用し、通常処理とmanaged watchの35秒は変更しない。既存budgetとの入れ子、上限の上書き、scope終了後の新しい送信を拒否し、終了時には進行中の比較通信も中断する。比較の全体期限をtransportと生成/査読で共有する。費用・回数・入力/出力・usage照合・失敗後停止の条件は緩めない。新しい時間枠で実AIを行うには、そのheadと時間/回数/費用/期限に一致するOWNER承認が必要。

[Azure Container AppsのHTTP ingress](https://learn.microsoft.com/en-us/azure/container-apps/ingress?tabs=bash)は240秒のrequest timeoutを持つ。[Next.jsのmaxDuration](https://nextjs.org/docs/app/api-reference/file-conventions/route-segment-config#maxduration)は配備platform向けmetadataであり、それだけで実ホストの時間制限を変えるものではない。AI全体230秒はDB予約後に始まるため、残る10秒で予約・保存等を必ず完了できるという保証はしない。実際のHTTP所要時間と240秒内の完了を実アプリ受入で確認し、失敗/応答不明はdurable reservationの読取だけで照合する。Azure設定は変更しない。timeoutの観測だけから、210秒で完了することや意味品質の改善を保証しない。

入力はsystem・schema・二重JSON escapeと余白を含めて90,000 bytes以内か事前検査する。全原文と最大長の生成欄を含む査読要求も、DB予約・最初の送信より前に検査する。生成後は実際の査読要求も再検査する。完全な計画が収まらなければ最初の送信前に停止し、対象を絞るよう案内する。managed watchの41回枠・本番承認は継承しない。

## Local provider failure evidence

The Local bridge retains safe HTTP metadata separately from any provider error
body. An explicitly configured private sink can preserve a complete HTTP400 body
within the existing 16 KiB limit; partial, aborted and oversized bodies are not
retained. The protected runner must encrypt this evidence before persistence.
There is no default raw-body sink, no body in public metadata, and no response or
usage reconciliation on this path. Private storage failure stops the operation.
Evidence capture alone never grants another request or weakens original-source QA.

Source v18 binds each quote to one declared clause or contiguous clause range.

the existing citation grid without rewriting text or filling missing roles.
Operator ranges must include every intermediate clause in W. The v17 decoder

create positive route tasks. Tasks supply no actors, conditions or endpoints.
Task coverage never replaces complete original-source QA: all component functions,

## Claim extraction v25: exact original quotations

The current per-claim request reads the unchanged original clauses directly.
It no longer duplicates the target claim as a character-separated coordinate
table. Each model-authored Q entry has `id`, `quote`, `before` and `after`.
The complete original claim must contain exactly one verbatim occurrence of
`before + quote + after`; missing, ambiguous or normalized text is rejected.
Only after that check may the decoder project the established occurrence into
the existing internal citation format. The raw model answer remains unchanged.
Context identifies an occurrence; it contributes no extra quoted-clause coverage.

This replaces the quotation-location representation, including its system,
input, schema and decoder contract. It retains every required literal-obligation
key and its link to an actual fact. Digit-only quote IDs, no duplicate/unused
declarations, the 12-clause and 80-character bounds, complete action/state and
guard checks, all original reading tasks and independent semantic QA remain.
The old coordinate and historical quotation decoders remain available for
historical replay; v24 responses cannot satisfy the v25 request.

Controlled input-only diagnostics localized a provider input refusal to a
