# 05 Overlap Analysis Spec

## 基本姿勢
拒絶リスクの推定は、**請求項に係る発明の認定**と**引用発明との対比**という構造に寄せて設計するべきです。審査基準でも、新規性・進歩性の判断は請求項に基づく発明認定と引用発明認定、その対比の上に進みます。citeturn3search0turn3search4

## 分析レイヤ
### L1 文字列一致
- 完全一致
- n-gram 類似
- 重要語一致

### L2 要素一致
- 名詞句抽出
- 動作/関係語抽出
- 制約条件抽出
- 入出力関係抽出

### L3 意味類似
- 埋め込みベースの近傍検索
- 同義表現・言い換えの補足

### L4 構造比較
- 「A が B を制御する」「C に応じて D を変更する」などの関係比較
- 単語一致でなく、要素間エッジの一致を見る

## スコアリング案
`overall = 0.30 * lexical + 0.35 * element + 0.20 * semantic + 0.15 * structural`

PoC ではこの重みを固定で始め、実案件を見て調整する。

## リスクラベル案
- High: 独立請求項の必須要素が多数一致
- Medium: 一部一致だが重要制約に差分あり
- Low: 語彙類似はあるが構造差が大きい
- Unknown: 解析不能、または原文不足

## レポートに必須の説明
- どの請求項を比較したか
- 一致した構成要素
- 一致しなかった制約
- 作用効果レベルの近似に過ぎない箇所
- 人手確認が必要な箇所

## 注意
- 類似度が高い = 新規性なし、ではありません
- 審査では進歩性についても、当業者が容易想到かどうかの論理付けが問題になります。citeturn3search2
- したがって本 PoC は「危険シグナル」を出す装置であって、最終判断機ではありません
