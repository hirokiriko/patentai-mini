# Patent Prior-Art Check Judge Sample Files

審査員が本番アプリを実際に操作するための、軽量な TXT サンプルです。

- アプリ本体: https://ca-patentai-mini.ambitiousocean-c848492c.japaneast.azurecontainerapps.io/
- 完成済みデモケース: https://ca-patentai-mini.ambitiousocean-c848492c.japaneast.azurecontainerapps.io/cases/14

## 使うファイル

1. `01-draft-patent-cold-dessert-ai.txt`
   - 最初にアップロードする特許案サンプルです。
   - 請求項抽出、検索式生成、検索キーワード補助、請求項記載チェックを確認できます。
2. `02-prior-art-cold-dessert-ai.txt`
   - 先行技術文献として取り込むサンプルです。
   - 4 層重なり分析で、語彙・構成要素・意味・構造の近さが見えやすい内容にしています。

## 推奨操作

1. アプリ本体を開きます。
2. トップページで新規ケースを作成します。
3. `01-draft-patent-cold-dessert-ai.txt` を特許案としてアップロードします。
4. 請求項抽出を実行します。
5. 検索式生成を実行します。
6. J-PlatPat 案内、検索キーワード補助、請求項記載チェックを確認します。
7. `02-prior-art-cold-dessert-ai.txt` を先行技術文献として取り込みます。
8. 4 層重なり分析を実行します。

## 注意

- このサンプルはデモ用の架空文書です。
- 特許性・新規性・進歩性を判断するものではありません。
- J-PlatPat で検索式を使う場合は、トップページの簡易検索ではなく、`特許・実用新案` → `特許・実用新案検索` の検索項目欄に貼り付けてください。
