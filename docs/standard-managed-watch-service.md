# 標準特許ウォッチ

公開・登録済みの日本特許を起点に、新着公報の確認候補を定期的に整理するサービスです。
本資料は提供内容の説明です。提供開始は所定の本番受入完了後とします。

| 項目 | 標準の内容 |
| --- | --- |
| 対象 | 1社、監視元は最大5件の日本特許。番号・版・指定請求項と原本を照合して登録します。 |
| 取得 | 運営者が週次で正規公報を手動取得し、締め時に公式配布一覧と照合します。 |
| 期間 | 原則26日〜翌月25日。初回は監視開始日から最初の25日まで（26日以降なら翌月25日）。 |
| 納期 | 月末。土日・祝日の場合は直前営業日。公開日、取得日、比較日、納品日は分けて記録します。 |
| 比較 | 候補選別後、採用公報の請求項全文と指定請求項全文・必要な従属参照を比較します。 |
| 納品 | PDFとCSVを運営者が手動メール納品。生成時点の内容・確認状態を固定し、再取得できます。 |
| 料金 | 標準は個別見積。対象追加、特別な集計、評価等のカスタムは別見積です。 |

正常に確認できた範囲で候補0件の場合も報告します。未取得・全文不足・未実行・失敗・結果不明は正常0件に含めません。不足の範囲をお知らせし、解消後は元の版に対応する補足・訂正版を作成します。以前の納品物は上書きしません。

運営者は処理状況と帳票の整合を確認します。ご利用者は公報原文を確認し、必要に応じて専門家と評価・最終判断を行います。AIの表示は調査・比較の支援であり、法的判断、侵害の有無、記載不存在の保証ではありません。

未公開発明・秘密技術資料、外国公報、権利状態・審査経過、製品侵害判定、明細書全頁・図面の比較、全公報のAI精読は標準対象外です。独立請求項のみを指定する場合は、その比較範囲を明記します。

顧客対応・監視設定・結果・納品物は契約中と終了後90日保管します。期限・所属を照合して削除し、共通公報は顧客情報と分けて扱います。バックアップの残存期間と復元時の再削除も運用手順で管理します。
